# FirstProject

OpenGL 기반 우주정거장 생존 공포 게임의 졸업작품 프로토타입.

## 현재 구현
- 이중 고리형 우주정거장: 중앙 관제실, 방사형 연결 통로, 공간별 설비와 환풍구망
- 생명유지실에서 시작해 설비를 복구하고 탈출정으로 이동하는 목표 진행
- 지도와 목표 표시, 환풍구 레이어, 기록 화면
- 심전도 체력 HUD, 달리기와 스태미너, Tab 원형 메뉴와 도구 5종
- HDR, 금속 재질, 블룸과 비네팅
- GLSL 외부 파일 관리와 빌드 후 셰이더 자동 복사

## 개발 환경
Windows / Visual Studio 2022 C++ / OpenGL / GLEW / freeglut.
`SimpleGame.sln`을 열고 플랫폼에 맞는 `Runtime/Win32` 또는 `Runtime/x64`의 DLL 두 개를 실행 파일 옆에 복사한다.
빌드 시 `SimpleGame/Shaders`의 셰이더가 출력 디렉터리의 `Shaders` 폴더로 복사된다. 배포 시 해당 폴더도 포함한다.

## 조작
WASD 이동, 마우스 시점, Shift 달리기, E 상호작용.
Tab을 누른 채 마우스로 도구 선택 후 놓기, 좌클릭 도구 사용.
M 지도, V 환풍구 표시, 휠 또는 +/- 확대·축소, 드래그 이동, C 지도 중심 복귀.
J 기록, H 도움말, ESC 마우스 해제·포착. 탈출 또는 체력 소진 후 R 재시작.
[ / ] 체력 미리보기.
