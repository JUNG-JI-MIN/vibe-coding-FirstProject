# FirstProject

OpenGL 기반 우주정거장 생존 공포 게임의 졸업작품 프로토타입.

## 현재 구현

- 준최종 기획서와 `Station_Early_Model.obj`를 기준으로 한 이중 고리형 정거장
- Framework → Scene → Object → Mesh 구조와 리소스 매니저의 공유 메시 캐시
- 헤더의 선언과 CPP의 구현 분리, GLSL 외부 파일 관리
- 플레이어 1명과 독립적인 행동 트리로 움직이는 동료 NPC 2명
- 에일리언의 순찰·소음 조사·추격·캐비넷 확인·시나리오 이벤트
- 동료 NPC의 플레이어 추종·위험 회피·문 밀기와 밸브 작업 지원
- 도킹 기록부터 비상전력 복구·샘플 교환·탈출정 가동까지 11장 진행
- 타이틀·탐사 준비·설정, 지도·기록·CCTV·격벽 조작
- 심전도 체력 HUD, 달리기와 스태미너, Tab 원형 도구 메뉴
- 캐비넷 은신과 문틈 시야, 양방향 유리 자동문
- HDR, 금속 재질, 블룸과 비네팅

현재는 로컬 1인 플레이로 동작하며 네트워크와 방 참가·생성 기능은 제거했다.

## 개발 환경

Windows / Visual Studio 2022 C++ / OpenGL / GLEW / freeglut.

`SimpleGame.sln`을 열고 플랫폼에 맞는 `Runtime/Win32` 또는 `Runtime/x64`의 DLL 두 개를 실행 파일 옆에 복사한다.
빌드 시 `SimpleGame/Shaders`의 셰이더와 `SimpleGame/Res`의 OBJ·MTL이 출력 디렉터리의 `Shaders`, `Res` 폴더로 복사된다.
배포 시 두 폴더도 함께 포함한다.

## 시작과 조작

타이틀 → 시작 → 탐사 준비 → 난이도·색 선택 → 탐사 시작.

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 / Shift | 이동 / 시점 / 달리기 |
| E 또는 E 유지 | 상호작용·작업·캐비넷 숨기와 나오기 |
| Tab 유지·마우스 선택·해제 | 도구 장착, 중앙은 맨손 |
| 좌클릭 | 손전등·스캐너·전압봉·구급상자 사용 |
| M / 휠 / 드래그·WASD / C | 지도 / 확대·축소 / 지도 이동 / 중심 복귀 |
| J / Esc | 기록 / 설정 및 일시정지 |
| V | 에일리언과 동료 NPC의 현재 행동 표시 |
| 관제실 F | CCTV 열기·닫기 |
| CCTV에서 Q·Z / N / B | 카메라 변경 / 격벽 선택 / 격벽 개폐 |
| 최종 단계 Q·Z / E | 압력 증가·감소 / 50~54에서 확정 |
| 결과 화면 R / Esc | 팀과 시나리오 재시작 / 타이틀 |
