# FirstProject

OpenGL 기반 3D 1인칭 함선 탈출 게임의 졸업작품 프로토타입.

## 현재 구현
- 20×20m 함선: 중앙 복도와 6개 구역, 금속 벽, 조명, 가구
- 1인칭 이동, 벽과 가구 충돌, 전체 배치 보기
- 체력에 따라 색과 박동 속도가 변하는 심전도 HUD
- Shift 달리기, 스태미너 소모·회복 및 최대치에서 페이드아웃
- 도구 슬롯 4개와 선택 표시

## 개발 환경
Windows / Visual Studio 2022 C++ / OpenGL / GLEW / freeglut.
`SimpleGame.sln`을 연다. 플랫폼에 맞는 `Runtime/Win32` 또는 `Runtime/x64`의 DLL 두 개를 실행 파일 옆에 복사한다.
기존 프로젝트의 라이브러리와 셰이더를 포함하며, 빌드 결과물과 개인 IDE 설정은 제외한다.

## 조작
WASD 이동, 마우스 시점, Shift 달리기, M 전체 배치, ESC 마우스 해제/포착.
1~4 도구 슬롯 선택. [ / ] 체력 감소/회복 미리보기.

## 미구현
적 AI, 소리·냄새 추적, 열쇠 획득, 퍼즐, 은신, 도구 사용, 탈출 판정.
관련 오브젝트는 현재 배치용이다.

기획과 상세 동작은 함께 제공한 TXT 문서를 참고한다.
사용자 요청에 따라 이번 작업의 빌드 및 실행 검증은 수행하지 않았다.
