20×20 함선 공간 프로토타입

작업 대상: 기존 SimpleGame.sln / SimpleGame 프로젝트
좌표: X=0~20, Z=0~20. 1단위=1m, 실내 높이 3m.
시작 위치: 중앙 복도 남쪽 (10, 17.5), 북쪽을 바라봄.

배치 (위쪽이 북쪽)
┌──────────┬──────┬──────────┐
│ 기관실   │ 중앙 │ 제어실   │
├──────────┤ 복도 ├──────────┤
│ 승무원실 │      │ 탈출구역 │
├──────────┤      ├──────────┤
│ 창고     │ 시작 │ 정비실   │
└──────────┴──────┴──────────┘

중앙 복도: X=8~12. 각 방의 출입구는 Z=4,10,16에 배치.
방 사이 가로 구획: Z=7,13.
외벽과 내부 구획, 출입구 프레임, 바닥 패널, 천장,
복도 유도등, 기관 설비, 제어 콘솔, 침상, 상자, 캐비넷,
정비실 열쇠 모형, 탈출 해치 모형을 렌더링한다.

조작
- WASD: 이동
- 마우스: 시점 회전
- M: 전체 배치 보기 / 1인칭 시점 전환
- ESC: 마우스 포착 해제 / 재포착
- 창 닫기: 종료

구현 범위
- 기존 GLEW/freeglut 환경을 활용한 OpenGL 호환 파이프라인 렌더링
- 별도 텍스처 및 모델 파일 없이 기본 도형으로 공간 구성
- 어두운 금속 색상, 청록색 유도등, 기관실 주황색 조명, 거리 안개
- 1인칭 카메라와 벽·가구 충돌, 프레임 시간 기반 이동
- 창 크기 변경 대응, 전체 배치 보기에서 플레이어 위치 표시

아직 구현하지 않은 항목
- 적과 소리·냄새 추적
- 열쇠 획득, 문 잠금 해제, 퍼즐, 캐비넷 은신
- 탈출 판정, 게임 오버, 재시작
출입구는 탐색을 위해 열린 프레임으로 구성했다.
캐비넷, 열쇠, 콘솔과 탈출 해치는 현재 시각적 배치용이다.

주요 파일
- SimpleGame/SimpleGame.cpp: 창 생성, 입력 및 프레임 갱신 연결
- SimpleGame/ShipScene.h: 공간 배치, 렌더링, 카메라와 충돌
- SimpleGame/SimpleGame.vcxproj: 새 헤더 등록

사용자 요청에 따라 빌드, 실행 및 화면 결과 확인은 수행하지 않았다.
기존 Renderer 파일은 유지하며 새 장면에서 사용하지 않는다.
이번 변경은 로컬 SimpleGame 프로젝트에 적용했으며 GitHub 업로드는 수행하지 않았다.
