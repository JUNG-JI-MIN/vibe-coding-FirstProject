우주정거장 재구성 — 구현 안내 v0.2
작성일: 2026-09-15
기준: 우주정거장_맵기획서_초안_v0.1.txt 및 이중 고리형 참고 이미지

1. 적용 범위
이번 구현은 이중 고리형 맵, 공간별 미술, 설비 복구에서 탈출까지의 진행을
기존 OpenGL 프로젝트에 연결하는 작업이다.
멀티플레이 통신과 괴물 AI를 완료한 버전은 아니다.
초안의 협동 조작은 먼저 한 사람이 순서대로 수행할 수 있도록 배치했다.
동시 조작이나 팀원 수를 필수 조건으로 강제하지 않는다.

2. 새로 채택한 구조
- 주 갑판 1개와 천장 위 환풍구층.
- 전체 생성 범위 X=0~200m, Z=0~200m. 실내 바닥 Y=0m.
- 중심 좌표 (100,100), 중앙 관제실 반경 11m.
- 바깥 고리: 중심 반경 66m, 폭 8m.
- 안쪽 고리: 중심 반경 38m, 폭 5m.
- 방사형 통로: 45도 간격 8개, 폭 4m.
- 주 갑판 천장 4.5m, 환풍구망은 천장 위 약 4.55~5.95m.
- 고리, 방, 연결 통로의 합집합으로 바닥과 벽을 생성한다.
- 곡선 경계는 1m 간격으로 샘플링한 삼각형에서 보간해 만든다.
- 이동은 같은 공간 정의와 가구 충돌 정보를 사용한다.

이 치수와 단일 갑판 구성은 구현을 위한 임시 결정이다.
원문에서 미정인 크기와 층수를 확정 기획으로 변경했다는 뜻은 아니다.
기존 100×100m 3개 층 맵을 새 기본 장면에서 사용하지 않는다.

3. 주요 구역 (중심 X,Z)
서쪽 위 생명유지실 LIFE: (16,66), 시작 위치 (16,67)
서쪽 아래 발전실 PWR: (20,136)
동쪽 위 의료실 MED: (184,71)
동쪽 아래 거주구 CREW: (185,125)
중앙 관제실 CMD: (100,100)
북쪽 연구실 LAB: (100,15)
남서쪽 창고 STORE: (60,180)
남쪽 도킹 베이 DOCK: (100,186)
북동쪽 탈출정 ESC: (182,24)

각 외곽 구역은 고리에 별도 연결 통로로 접속한다.
외곽 고리의 북동~동쪽 일부에는 손상된 격벽이 있다.
해당 격벽은 열리지 않지만 안쪽 고리와 방사형 통로로 우회할 수 있다.
관제실 출입은 카드·전력 조건으로 제한되며 두 고리의 순환 이동을 차단하지 않는다.

5. 환풍구망
- 두 고리를 따라 이어지는 순환 연결망.
- 8개 방사형 분기로 관제실과 고리 사이 연결.
- 주요 방마다 연결 분기와 환풍구 덮개.
- 환풍구 노드와 연결 정보를 별도로 보관해 향후 괴물 경로 계산에 연결 가능.
- 천장 개구부, 덮개 프레임, 내부 통로 벽과 상부를 배치했다.
- 지도에서 분홍 점선은 연결 통로, 분홍 X는 방·복도 출입구.
- 연구실 댐퍼 차단 중에는 해당 분기를 다른 색으로 표시하고 덮개를 닫는다.
- 괴물 이동, 출현, 소리, 환풍구 추격 AI는 아직 연결하지 않았다.
- 플레이어의 환풍구 진입은 이번 범위에 포함하지 않았다.

6. 미술과 렌더링
- 바깥 고리: 회백색 도장 금속, 작업등, 우주가 보이는 창문.
- 안쪽 고리: 어두운 금속, 주황색 정비등, 곡선을 따라가는 노출 배관.
- 생명유지실: 녹색 산소 처리 설비, 배관, 국소적인 젖은 표면과 누출 증기.
- 발전실: 대형 설비, 배선 트레이, 노란 경고 표시.
- 의료실: 밝은 금속 침대와 분리 프레임.
- 거주구: 천 재질 침상, 수납장, 덮인 사고자 모형.
- 관제실: 중앙 지도 테이블과 둘레 콘솔.
- 연구실: 실험대와 밀폐 장치.
- 창고: 외곽 선반과 가동되는 운반대.
- 도킹 베이: 정비선 모형과 상부 크레인.
- 탈출정: 좌석과 중앙 통로.
- HDR, 톤 매핑, 약한 빛 번짐, 강화된 비네팅, 안정화된 반사 계산 유지.
- 공간 조명 색과 전력 상태가 실제 셰이더의 광원 에너지에 반영되도록 변경.
- 정적 기하를 재질별 버퍼로 묶어 그리며 외부 모델·텍스처 다운로드는 필요하지 않다.
- 환경 반사, 실시간 그림자, 정교한 파손·사용감 텍스처는 아직 없다.

7. 지도와 UI
- 이전 3층 선택 대신 단일 주 갑판 설계도.
- M: 지도 열기/닫기.
- V: 환풍구망 표시 켜기/끄기.
- 마우스 휠 또는 +/-: 지도 확대/축소.
- 지도에서 왼쪽 버튼 드래그: 이동, C: 전체 위치로 복귀.
- 초록 원: 플레이어, 금색 마름모: 현재 목표.
- 금색 격벽: 닫힘, 초록 격벽: 열림.
- J: 최근 기록, H: 조작 안내.
- 기존 체력 심전도, 달리기·스태미너, Tab 원형 도구 메뉴 유지.
- 스캐너는 기존 코어 대신 가까운 미완료 조작 지점을 탐지한다.
- 카드와 탈출 부품 확보 상태를 오른쪽 HUD에 표시한다.

8. 조작
WASD 이동, 마우스 시점, Shift 달리기.
E 누르기 또는 유지로 상호작용.
Tab 유지 → 마우스 방향 선택 → Tab 해제로 장착. 중앙에서 해제하면 맨손.
좌클릭으로 도구 사용. 드릴·렌치는 유지 조작에도 사용 가능.
ESC 마우스 포착 해제/복귀.
[ / ] 체력 표시 확인용 임시 입력.
탈출 완료 또는 체력 0일 때 R 재시작.

9. 기존 구현과의 관계
- 실행 시작점은 SimpleGame.cpp → StationScene으로 바뀌었다.
- StationLayout.h: 고리·방·통로·창문·가구·환풍구 및 충돌.
- StationMission.h: 22개 조작 지점, 전력·카드·부품·격벽·탈출 상태.
- StationScene.h: 이동, 도구 연결, 지도, HUD, 기록, 렌더링.
- 기존 ShipScene / ShipLayout / ColorQuest / PipePuzzle 파일은 보관한다.
  현재 기본 실행에는 사용하지 않으며 4색 코어와 2층 카드 진행은 새 장면에 없다.
- 원문 기획서는 수정하지 않는다.

10. 한계와 확인 상태
- 멀티플레이 네트워크, 동기화, 접속 종료 대응은 미구현.
- 괴물 AI, 전투, 실제 추격과 은신은 미구현.
- 협동 퍼즐은 현재 1인으로 순차 수행 가능한 설비 조작 형태다.
- 진행은 메모리에 유지되며 앱 종료 후 저장·불러오기는 없다.
- 기본 도형과 절차적 기하를 사용한 프로토타입이며 최종 미술 자산이 아니다.
- 빌드, 실행, 이동 및 시각 결과 확인은 사용자 요청에 따라 수행하지 않았다.
- 이번 변경은 로컬 작업 폴더에 적용했으며 Commit/Push는 하지 않았다.
