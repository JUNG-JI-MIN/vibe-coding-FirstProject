# 002: 커밋에 요청 프롬프트와 변경 내용을 함께 기록

- 날짜: 2026-10-14 (Asia/Seoul)
- 상태: 채택. 사용자가 앞으로의 커밋에 요청 프롬프트와 변경 내용 정리를 지시함.
- 요청: “앞으로 커밋할때는 프롬프트와 변경내용을 정리해서 커밋해”.
- 결정: 커밋 제목은 핵심 변경, 본문은 요청 프롬프트 요약·변경 내용·검증으로 작성한다.
- 기록: 작업 인계에도 요청과 추가 지시를 짧게 요약한다. 대화 전체를 누적하지 않는다.
- 범위: 데스크톱과 노트북의 이 저장소 작업에 공통 적용한다.
- 이유: 변경의 목적을 Git에서 바로 파악하고 다른 PC의 Codex가 요청과 구현을 연결할 수 있게 한다.
