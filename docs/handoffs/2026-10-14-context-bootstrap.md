# 두 PC 공통 기준 초기화

- 날짜: 2026-10-14 (Asia/Seoul)
- 요청 프롬프트: 두 PC 설계 동기화와 변경분 확인 방식 도입, 노트북용 전달 프롬프트 작성.
- 추가 지시: 앞으로 커밋마다 요청 프롬프트·변경 내용을 정리하고, 이번 변경은 Commit/Push.
- 코드 확인 기준: `07f5b2c`; 이 기록을 포함한 공유 커밋은 전달 시 확정된다.
- 변경: 루트 AGENTS, 짧은 현재 상태, 모듈 경로, 설계 결정과 변경분 읽기 도구를 추가.
- 변경: `.local/`을 Git에서 제외하여 각 PC의 확인 위치를 따로 유지.
- 변경: 요청 요약·변경 내용·검증을 커밋 본문과 인계에 남기는 공통 규칙 추가.
- 이유: 장문 전체 재독 없이 두 PC가 같은 설계와 최근 변경을 이어받기 위함.
- 관련 파일: `AGENTS.md`, `docs/context/`, `docs/decisions/001-shared-context.md`, `tools/read-context.ps1`, `.gitignore`, `README.md`.
- 게임 코드: 변경 없음. DirectX 이식은 방향만 기록했고 착수하지 않음.
- 문서 지위: 확장 기획 v0.3은 제안이며 현재 구현과 구분.
- 검증: PowerShell 7.6에서 문법·JSON·초기 실행을 확인하고 별도 Git 테스트 저장소의 통합 확인 15개 통과.
- 검증 범위: 커서 저장/재조회, 로컬·커밋 변경, 출력 제한, 모듈·인계 표시, 잘못된 커서·브랜치·저장 요청 처리.
- 호환: Windows PowerShell 5.1 문법 검사 통과. 5.1 실행은 이 PC의 스크립트 실행 정책에 막혀 미검증.
- 미검증: 게임 빌드·실행·전체 플레이, 다른 PC에서의 실제 Git 전송.
- 다음: 코드와 문서를 함께 공유한 뒤 노트북에서 도구 실행, 관련 변경 확인, 확인 커서 저장.
- 인계 읽기: `docs/context/sync-guide.md`의 시작/종료 절차를 사용.
